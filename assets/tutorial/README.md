# Tutorial screen captures

These are actual Crepuscular Homunculus **0.26.19** screens rendered by the
native desktop emulator, not hardware photographs or redrawn illustrations.
They show example states for the [illustrated guide](../../docs/ILLUSTRATED_GUIDE.md).
The examples are not a song installed automatically with the firmware.

Fourteen screens were captured with scripted panel input and converted losslessly
from the native 240 × 240 framebuffer to PNG. HOME and the piano-roll example
reuse the final release's native captures; the piano-roll picture is enlarged
three times with nearest-neighbor scaling. No pixels or control labels were
invented. The instrument's artwork and existing credits are retained.

These images explain controls. They do not measure device performance or qualify
hardware behavior. See [testing](../../docs/TESTING.md) for validation scope.
